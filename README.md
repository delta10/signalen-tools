# Signalen tools

Tools to quickly build additional questions and routing expressions for Signalen.

This project is a React application built with Vite, TanStack Router, Tailwind CSS, and shadcn/ui.

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the production bundle:

```bash
npm run build
```

Run linting:

```bash
npm run lint
```
